# Source Policy

## Objetivo

Mantener trazabilidad entre el contenido educativo y las fuentes utilizadas.

---

# Categorias

## CICDE

Bibliografia expresamente indicada en los Lineamientos CICDE 2026.

Ejemplos:

- Brunner y Suddarth;
- Potter;
- Wong;
- Balderas;
- Hernandez Sampieri;
- bibliografia farmacologica indicada por CICDE.

## PANAMA_OFFICIAL

Fuentes oficiales panamenas.

Ejemplos:

- MINSA;
- legislacion panamena;
- ANEP;
- CSS cuando corresponda;
- documentos oficiales vigentes.

## COMPLEMENTARY

Fuentes confiables utilizadas para complementar o actualizar.

Ejemplos:

- OMS;
- OPS;
- CIE;
- editoriales academicas;
- guias clinicas reconocidas;
- literatura cientifica pertinente.

---

# Jerarquia

Cuando corresponda:

1. Temario oficial CICDE para definir que estudiar.
2. Bibliografia indicada por CICDE.
3. Norma oficial vigente de Panama.
4. Fuentes internacionales o academicas complementarias.

La jerarquia no significa ignorar una norma vigente.

Las diferencias deben documentarse.

---

# Prohibiciones

No:

- inventar autores;
- inventar paginas;
- inventar citas;
- afirmar que un texto proviene de un libro sin comprobarlo;
- utilizar blogs sin control como fundamento clinico;
- utilizar contenido generado por IA como fuente bibliografica;
- ocultar que una fuente no pudo verificarse.

---

# Verificacion

Una fuente puede marcarse VERIFIED solamente cuando se haya confirmado razonablemente:

- identidad;
- titulo;
- autor u organizacion;
- fecha cuando exista;
- procedencia;
- relacion con el tema.

---

# Contenido obtenido de libros sin acceso completo

Si solamente se dispone de:

- indice;
- ficha editorial;
- fragmento;
- vista previa;
- cita secundaria;

no afirmar que conocemos el contenido completo del capitulo.

Se debe registrar exactamente que parte pudo comprobarse.

---

# Actualizaciones

Para temas sujetos a cambios frecuentes se debe verificar informacion vigente.

Especial atencion a:

- vacunacion;
- normas MINSA;
- politicas publicas;
- legislacion;
- medicamentos;
- protocolos;
- obstetricia;
- urgencias;
- control de enfermedades.

---

# Preguntas

Cada pregunta validada debe tener al menos una fuente asociada.

Cuando la respuesta dependa especificamente de una norma panamena, la fuente oficial panamena debe quedar asociada.

---

# Auditoria

La plataforma debe permitir en el futuro responder:

"De donde salio esta informacion?"

sin depender de la memoria del desarrollador o del modelo de IA.
